# Gym Management System Case Study 🏋️‍♂️

## About the Project
Hi groupmates! Sa repository na ito nakagrab ang source code at documentation para sa ating **Gym Management System Case Study**, isang software solution na ginawa para ma-streamline ang gym operations, member tracking, at payment processing. Built using Python, pwedeng-pwede tayong mag-collaborate dito nang tuloy-tuloy. Para kusa at automatic na ma-save at ma-push ang mga ginagawa niyo sa VS Code papunta sa repo na ito, mag-install lang kayo ng **GitDoc** extension at i-enable ang Auto Save sa inyong VS Code Settings. On every save, automatic na mag-co-commit at push ang mga bagong updates niyo para sa ating seamless workflow!

---

## 📋 Prerequisites

Before running the application, ensure you have the following installed on your machine:

- **Python 3.x** (Python 3.10+ recommended)
- **Visual Studio Code**
- **Git** installed on your system

ITO ANG FULL STEPS HOW TO AUTOSAVE YOUR WORK HERE SA REPO CHANGE USERNAME NALANG:
Step 1 — First, enter git clone [https://github.com/USERNAME/gym-management-system-CASE-STUDY.git](https://github.com/USERNAME/gym-management-system-CASE-STUDY.git) in the terminal to copy the project folder to their local computer, and then run cd gym-management-system-CASE-STUDY to navigate directly inside the project directory. 

Step 2 — Next, open VS Code, go to File > Open Folder..., select the gym-management-system-CASE-STUDY folder, and open the Extensions view (Ctrl + Shift + X) to search for and install GitDoc (by Jonathan Carter). 

Step 3 — Then, open VS Code Settings (Ctrl + ,), search for Files: Auto Save, and change its setting to afterDelay so VS Code automatically saves code edits in real time. 

Step 4 — Finally, run git remote set-url origin [https://github.com/USERNAME/gym-management-system-CASE-STUDY.git](https://github.com/USERNAME/gym-management-system-CASE-STUDY.git) ; git add . ; git commit -m "Initial commit" ; git push -u origin main in the VS Code PowerShell terminal to perform an initial push and link their local branch to the remote repository—from this point forward, every time they edit and save a file, GitDoc will automatically commit and push their changes straight to GitHub without needing any further terminal commands.
